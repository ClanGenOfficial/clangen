# Pelt Parts Visual Guide

Visual guide to all pelt parts, located in `sprite/pelt_part_mask.png`. For visibility, the masks are shown in blue on a white background, with lineart.

| ![image][MASKEDPATTERNLIGHT]    | MASKEDPATTERN <br><br> Secondary pattern for the Masked Pelt, typically a lighter color. |

| ![image][MACKERELPATTERN]       | MACKERELPATTERN <br><br> Pattern for the Mackerel Pelt.                                  |

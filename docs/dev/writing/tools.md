Tools that may help with writing for ClanGen.

## IDE Tools
### Visual Studio Code
Visual Studio Code will do simple checks and autocompletion for certain types of JSON files:

* Thoughts
* Short events
* Patrols

There are also starter objects that will appear under autocomplete when you type: `clangen-patrol-minimal` and `clangen-patrol-outcome-minimal`. These are simple JSON objects with only the required fields. They can serve as a good jumping off point when adding new patrols.

These features should work out of the box as long as you open the project in Visual Studio Code.

## Unofficial Tools
!!! warning
    These tools are unofficial. They may be out of date or have inaccuracies.

* [**Pronoun Tester**](https://cgen-tools.github.io/pronoun-tester/) - A tool that will test pronoun tags. It also has a "Pronounify" button that will automatically tag they/them pronouns and verbs.
* [**Patrol Helper**](https://cgen-tools.github.io/patrol-helper/) - A somewhat outdated tool that may help with creating JSON objects for patrols.

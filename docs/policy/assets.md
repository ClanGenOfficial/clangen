# Assets

*N.B. "Assets" refers to any writing or artwork present within the game that is not code.*

## Naming Assets

### Internal names
Where possible, the creator/creators of the asset choose the internal representation for the name. The only time that other internal names may be requested is in the event of a mechanical problem (e.g., too similar to an existing name). Seniors reserve the right to veto with provided reasoning.

### Player-facing names
Contributors are welcome to provide feedback on PRs that contain player-facing names. This does not guarantee that a change will be made.

## Replacing Assets
ClanGen reserves the right to replace assets at any time. This will only be done with a reasonable justification. 

If you wish to replace an asset, you are welcome to raise it for discussion in the Discord. If the community agrees and/or seniors approve, you may proceed with the replacement. Note that any replacement will be held to the same standards as new assets, with the additional constraint of improving upon the original in the ways stated by the initial justification (if not already covered by the asset standards).

## Removing Assets
In line with [CC-BY-NC 4.0 (external link)](https://creativecommons.org/licenses/by-nc/4.0/), contributors are welcome to remove assets at any time. However, the seniors would like to request that any removed assets be replaced with an equivalent. Please contact the seniors if you wish to remove assets from ClanGen. A project to replace the work will be initiated, with the assets being removed once replacements are created. 

Note that you may only request removal of content that you yourself have contributed (as evidenced by Git commit). In the event of a collaborative asset, *all* collaborators must agree to the removal.

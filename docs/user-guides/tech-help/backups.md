Back ups of save files. use message in tech helper chat

Windows:
1. open data directory in settings / opendatadirectory.bat in game folder
2. right click saves folder to copy
3. paste in a save spot separate from the clangen directory (such as desktop)
4. rename folder (optional)
5. download new version, delete old version
6. open new versions open data directory
7. take the contents of the copied saves folder and copy+paste it into the newly generated saves folder
8. the file path should be clangen/saves/clan instead of clangen/saves/saves/clan

macos:
1. open data directory in settings (if unable to open game, open a modded application and open the data directory in its settings, then nagivate to clangen's folder)
2. right click the saves folder and select "duplicate" (NOT alias)
3. drag the duplicate to a separate from the clangen directory (such as downloads)
4. rename folder (optional)
5. download new version, delete old version
6. open new versions open data directory
7. take the contents of the duplicated saves folder and copy+paste it into the newly generated saves folder

chromeos:
1. open data directory in settings / manually nagivate to saves (file path ~.local/share/ClanGen)
2. open saves folder, use ctrl+a and ctrl+c to copy all contents
3. make a new folder separate from the clangen directory (such as downloads)
4. rename folder to "cg saves backup" or similar
5. paste (ctrl+v) all contents into the created folder
6. download new version, delete old version
7. open new versions open data directory
8. take the contents of the copied saves folder and copy+paste it into the newly generated saves folder
